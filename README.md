# 🎧 Spotify Clone

A Spotify-inspired music player built using HTML, CSS, and JavaScript.

## ✨ Features
- Play and pause music
- Next and previous song controls
- Interactive playlist cards
- Music seek bar
- Current time and song duration
- Sidebar playlist interactions
- Responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📚 What I Learned
- DOM manipulation
- JavaScript event listeners
- Audio playback controls
- Updating song progress and duration
- Responsive UI design

## 🚀 About the Project
This project was created to practice frontend development and improve my JavaScript skills by building an interactive music player.
